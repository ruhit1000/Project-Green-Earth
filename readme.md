# Project Green Earth

## Overview

**Project Green Earth** is a web-based project designed to promote environmental awareness and provide information related to nature, sustainability, and the Earth. The website presents dynamic environmental data and information through a clean and interactive interface.

The project was built using **HTML5, TailwindCSS, and Vanilla JavaScript**, focusing on creating a responsive and user-friendly layout. External APIs are used to fetch and display real-time data dynamically on the website. The site includes multiple sections presenting environmental information, interactive buttons, and a dedicated **About Us** page that explains the goal and purpose of the project.

The overall goal of the project is to combine modern web development practices with environmental awareness while building an interactive and responsive web interface.

---

## Features

- Responsive design that works across different screen sizes and devices

## Challenges

One of the main challenges in this project was **fetching and handling data from external APIs** using Vanilla JavaScript. Managing asynchronous data and displaying it correctly on the user interface required understanding how API requests work and how to dynamically update the DOM.

Another challenge was **ensuring responsiveness across different devices** while maintaining a clean layout. Balancing multiple sections, dynamic data, and interactive elements required careful use of TailwindCSS utility classes and responsive design techniques.

Additionally, implementing **interactive buttons and functional elements** while keeping the JavaScript code organized required experimenting with event handling and DOM manipulation.
